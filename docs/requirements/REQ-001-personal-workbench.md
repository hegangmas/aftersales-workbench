# REQ-001：售后个人工作台

- 状态：待业务最终签收；技术门禁与阿里云实机部署已通过，待业务负责人结合当前交付版本完成最终签收。
- 确认依据：11 月 23 日售后工单会议文字记录、11 月 25 日经认可的效果图，以及 V1.1 架构与 UI 基线约定。
- 确认基线：已随 V1.1 严格重建演进至 Git 提交 `a06eb24`（Flyway V9）。

## 目标与范围

让售后人员围绕当前问题单集中查看设备摘要、历史问题、处理记录和回访安排，并承接问题单跟进与 V1.1 状态流转。现行已确认的 V1.1 形态采用「顶栏固定 5 项一级导航 + 三栏个人工作台 + 6 节点进度条」，并保持工单池、调度大屏、知识库与管理端按角色隔离的整体交互一致性。

## 业务规则

- 保持已有认领、权限、状态流转、跟进、回访和现场单规则；对无权处理的问题单只读展示或按现有流程认领。
- 操作记录供交接参考；设备和历史问题单查询失败时提示不可用，不显示为无记录。
- 客户与地址、真实充电记录和告警、电话、素材收集与外部审批目前未接入；设备摘要来自现有模拟接口，不得把模拟或未接入的信息展示为真实结果。
- 客户资料收集、电话弹屏、自动故障判断和真实外部系统集成为后续需求，具体方案和业务规则需确认。

## 本轮验收标准

1. 从工单池或我的待办打开问题单后，三栏个人工作台展示 6 节点进度条、标题、状态、负责人、描述、处理记录、证据登记及回访/派单联动信息。
2. 有处理权限时可保存跟进并推进状态；无权限或未认领时沿用现有授权与认领规则。
3. 顶栏固定 5 项一级导航（`工作台`、`工单`、`设备`、`知识库`、`管理`），支持从工作台在查桩建单、工单页签与只读知识库间切换，外部角色按权限隐藏受限菜单与入口。
4. 外部模拟数据与未接入能力明确标识，查询失败可辨别。
5. 适配桌面端三栏布局及窄屏响应布局，后端状态流转与前后端契约测试全部通过。
