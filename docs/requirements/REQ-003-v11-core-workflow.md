## 业务规则与操作流程

### 1. 建单渠道、故障发生时点、默认 SLA 与防重复建单

- **建单渠道标签**：支持在建单与展示时标识来源渠道，覆盖 `400`（400 热线）、`miniapp`（小程序）、`provider`（服务商）、`wecom`（企微）、`phone`（电话），同时兼容历史无渠道标签或既有默认来源的工单。
- **故障发生时点**：建单时支持录入故障发生时间（精确到分钟），用于与模拟充电记录/告警时间对照；未填写时允许留空或由后续排查补录。
- **默认 SLA 时效**：建单时由服务端自动生成并保存默认 SLA 截止时间（`slaDueAt`），供总表、待办与工作台计算剩余时间及超时提醒。
- **同桩未闭环工单提醒**：在查桩及建单提交前，若该桩号存在未闭环（非已结案/已答复/已转出等终态）的工单，系统给予显著提醒并展示历史未闭环工单入口，引导坐席优先合并跟进或核对现象，防止重复建单；确属不同问题时允许坐席确认后继续新建。

### 2. 挂起（4 类原因）与回池共享机制

- **统一落库状态 `suspended`**：因外部或配合条件暂无法推进时，可将处理中（`processing`）的问题单置为 V1.1 统一挂起状态 `suspended`（修正历史 `'waiting'` 落库残留），写入 `state_transition_log`，并必须选择 4 类原因之一及填写说明/下一步计划：
  1. **待客户配合/不在现场**（如客户暂未到桩边、待客户反馈复测结果）；
  2. **待二线/技术会诊**（如需要技术二线或研发分析日志/报文）；
  3. **待上游/第三方核实**（如等待平台数据核查、车企/服务商反馈）；
  4. **待配件/约定时间**（如与客户约定晚间回访、等待备件或外部排期）。
- **回池共享机制**：挂起时支持同时释放回团队共享池（`returnToPool=true`），此时工单**保持 `suspended` 状态并释放当前责任人**（`owner=early`），使接班坐席可在总表/待办池中查看挂起原因、已有记录与计划动作，并通过认领动作接续处理；从 `suspended` 恢复后回到 `processing` 排查/处理流程，所有挂起、回池与恢复操作均写入活动时间线与状态流转日志。

### 3. 简单工单快通道

- **适用场景**：一般咨询、操作指引后当场恢复、误报/非故障说明等无需上门或换件的简单问题单，可通过快通道快速推进至待验收阶段。
- **严格遵守 V1.1 状态机与强制完结依据**：执行快通道（`quick-close`）时不再直跳历史 `resolved` 终态，而是严格遵循 V1.1 状态机由 `processing` 流转至 `pending_accept`（待验收）；操作时必须填写可核查的完结依据（如客户口头/消息确认已恢复、后台核实说明、咨询答复要点等），服务端将核验依据、操作人、活动记录与 `state_transition_log` 状态流转日志一并落库，随后经标准验收闭环进入 `closed`（已结案）。
- **禁止边界（服务端校验拦截）**：
  - 处置方式为「换装（整桩更换）」「换件」「上门（现场派单）」的工单，禁止走快通道；
  - 已关联未结束现场单、或存在未处理高风险/强制约束的工单，禁止走快通道；
  - 违规调用快通道时，服务端返回 `400`/`409` 及明确中文提示，保持原状态不变。

### 4. SLA 超时与妥协工单升级旁路

- **不破坏主状态**：升级与妥协标识作为独立于主业务状态（如待认领、处理中、待排查、已挂起、待回访、待派单、现场处理中、待验证等）的旁路属性保存，执行升级、解除或标记妥协均不覆盖问题单当前所处的排查/等待/现场/验证主状态。
- **SLA 超时识别**：当未闭环工单当前时间超过 `slaDueAt` 时，系统自动标记为 SLA 超时并在总表与详情高亮提示。
- **升级旁路**：支持将工单升级至二线（`l2`）或专家/主管（`expert`），记录升级原因与升级时间，并在时间线留痕。
- **妥协工单标记**：针对因客户情绪、特殊保供或现场条件限制需先行妥协处置的工单，支持标记为「妥协工单」并记录原因，便于后续质量复核与专题追踪。

### 5. 两段式故障 SOP、证据包登记与 A/B/C 判定分级

- **两段式故障 SOP**：根据工单故障分类匹配对应的排查 SOP，明确取证模式并拆分为两段展示：
  - **第一段：客户可执行步骤（≤3 步）**：面向一线坐席引导客户在现场或电话中快速自查，严格控制在 3 步以内（如指示灯确认、断电重连、更换车辆/重插枪测试）；
  - **第二段：上门验证步骤**：面向需现场服务或技术复核的场景，列出到场后的核查、测量与试充验证要求。
- **证据包登记**：
  - 支持围绕当前问题单追加与查看证据条目，字段涵盖：证据类型（如照片、短视频、时序日志/故障时点、平台数据快照、同站对照/替换测试等）、来源（坐席代录、客户描述、平台模拟等）、**本地文件名（元数据记录，一期不上传真实二进制文件）**、文字备注、登记人与登记时间。
- **A / B / C 判定分级与换装校验**：
  - 支持对问题单设置判定分级（`A` / `B` / `C`）与拟定处置方式（远程解决 `remote`、换件 `part`、换装 `replace`、上门核查 `onsite`）：
    - **A 级**：事实与证据充分，指向明确（可执行对应远程、换件或换装处置）；
    - **B 级**：有一定依据但仍需进一步核实或补证（按规则安排复测、上门查验或补证）；
    - **C 级**：证据不足或未达定责条件——**服务端强制禁止 C 级选择或提交「换装」处置**。
  - **换装证据门槛与模拟自动校验**：选择或提交「换装」处置时，问题单必须已登记至少一条有效证据；服务端执行规则校验并生成「模拟自动校验留痕」（明确标注为模拟自动规则校验通过/拦截记录），写入活动与工单字段，不替代正式业务审批系统。

## 数据来源、接口与权限

- **数据来源边界**：外部设备档案、400 话单、充电会话与实时告警仍由现有模拟服务提供，界面与响应须明确标注「模拟数据」，不得伪装为生产实时数据。
- **数据库兼容性**：通过新的 Flyway 迁移脚本（如 `V8` 及后续版本）增量扩展 `problem` 表字段与新增 `evidence_item` 等证据元数据表；新增列必须可空或具备安全默认值，不得修改已有 `V1`–`V7` 迁移脚本或破坏历史问题单数据。
- **接口与并发权限约定**：
  - 沿用现有 Session 登录校验、CSRF 防护、写操作 `Idempotency-Key` 幂等与 `expectedVersion` 乐观锁校验（版本或状态冲突返回 `409` 与中文提示）；
  - 沿用现有「当前负责人或管理员可操作，其他坐席无权返回 `403`」权限规则；无主单或已回池工单需先认领（管理员可按现有规则处理）。
  - 保持现有全部接口路径、请求/响应字段与状态流转规则向后兼容，确保已有接口调用方不受破坏。

## 异常情况及待确认问题

- **异常情况**：
  - C 级工单选择换装、无证据提交换装、换装/换件/上门工单误点快通道、未选挂起原因或未填完结依据时，前后端均须拦截并给出清晰的中文错误提示，保留用户表单草稿。
  - 并发操作（如两人同时认领回池工单、同时触发挂起/快通道/升级）时，后提交方收到 `409` 提示并可一键刷新获取最新状态与版本号。
  - 历史旧单缺失 `faultOccurredAt`、`channel`、`grade`、`slaDueAt` 等新字段时，页面安全兜底展示为「未记录」或默认状态，不报错崩溃。
- **待后续阶段确认**：
  - 各渠道实际对接后，400/企微/小程序入单字段映射与自动去重规则；
  - 不同产品型号/项目对应的正式 SLA 时效配置与二线/专家升级自动路由阈值；
  - 真实对象存储附件上传、文件大小/格式限制及换装正式审批流对接。

## 本轮验收标准

1. **建单与防重**：创建问题单支持选择 `400` / 小程序 / 服务商 / 企微 / 电话渠道并录入故障发生时点，建单后自动写入默认 SLA 截止时间；当目标桩存在未闭环问题单时，建单前界面明确提醒并可跳转查看原单。
2. **挂起与回池**：支持选择 4 类挂起原因挂起问题单并填写说明，支持将工单释放回池共享；其他有权限坐席在总表/待办可见挂起原因并可认领续办、恢复推进，时间线完整留痕。
3. **快通道与边界拦截**：简单咨询/远程已恢复工单填写完结依据后，可通过快通道严格按 V1.1 状态机由 `processing` 流转至 `pending_accept`（待验收）并记录核验依据与状态流转日志，随后经标准验收闭环至 `closed`；对已选换装、换件、上门或存在未结束现场单的工单调用快通道时，服务端明确拒绝并返回中文原因。
4. **SLA 与升级/妥协旁路**：工单可独立设置二线/专家升级与妥协工单标记，操作前后工单主状态保持不变；超过 SLA 截止时间的未闭环工单在总表与详情准确展示超时徽标。
5. **SOP、证据包与 A/B/C 分级**：三栏工作台按故障分类展示两段式 SOP（客户步骤 ≤3 步 + 上门验证步骤）；支持登记证据类型、本地文件名元数据与备注并展示列表；C 级判定禁止选择换装，换装须至少有一条已登记证据且服务端生成模拟自动校验留痕。
6. **总表徽标与移动端切换**：网页总表可见全部新增状态、渠道、SLA 超时、升级、妥协与 A/B/C 徽标；三栏工作台完整展示各项新能力，并在移动端支持「主要信息 / 全部信息」两档平滑切换；所有外部档案与 400/充电/告警明确标注模拟数据。
7. **现有接口与回归兼容**：原有问题单列表、详情、认领、跟进、回访、转交、现场单关联/回执/撤回、账号与改密接口保持 100% 向后兼容；在测试环境启动后执行 `python3 scripts/smoke.py` 全部用例一次通过。
